  1. CREATE A RECORD  POST /api/v1/records
     Expected: 201 Created
     Idempotency-Key prevents duplicates on retry
──────────────────────────────────────────────────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -H "X-Idempotency-Key: 11111111-1111-1111-1111-111111111111" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"diagnosis\":\"Seasonal flu with mild fever\",\"entries\":[{\"entryName\":\"Paracetamol 500mg\",\"quantity\":2.0,\"frequency\":\"Twice daily\",\"duration\":5,\"instructions\":\"Take after meals\"},{\"entryName\":\"Vitamin C 1000mg\",\"quantity\":1.0,\"frequency\":\"Once daily\",\"duration\":7,\"instructions\":null}]}"

── Missing diagnosis → 400 with fieldErrors ──────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"entries\":[{\"entryName\":\"Med\",\"quantity\":1.0,\"frequency\":\"Daily\",\"duration\":5,\"instructions\":null}]}"


── Future date → 400 (@PastOrPresent violated) ───────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2030-01-01\",\"diagnosis\":\"Test\",\"entries\":[{\"entryName\":\"Med\",\"quantity\":1.0,\"frequency\":\"Daily\",\"duration\":5,\"instructions\":null}]}"


── Quantity = 0 → 400 (@DecimalMin inclusive=false) ──────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"diagnosis\":\"Test\",\"entries\":[{\"entryName\":\"Med\",\"quantity\":0.0,\"frequency\":\"Daily\",\"duration\":5,\"instructions\":null}]}"


── Duration > 3650 days → 400 (@Max(3650) violated) ─────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"diagnosis\":\"Test\",\"entries\":[{\"entryName\":\"Med\",\"quantity\":1.0,\"frequency\":\"Daily\",\"duration\":9999,\"instructions\":null}]}"


── Empty entries → 400 (service-layer guard) ─────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"diagnosis\":\"Test\",\"entries\":[]}"


── Non-existent user → 404 Not Found ─────────────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":9999,\"clientId\":1,\"recordDate\":\"2026-10-16\",\"diagnosis\":\"Test\",\"entries\":[{\"entryName\":\"Med\",\"quantity\":1.0,\"frequency\":\"Daily\",\"duration\":5,\"instructions\":null}]}"


── Non-existent record → 404 Not Found ───────────────────────

curl.exe -X GET http://localhost:8080/api/v1/records/9999 ^
  -u admin:admin123


── Wrong path variable type (/records/abc) → 400 ────────────

curl.exe -X GET http://localhost:8080/api/v1/records/abc ^
  -u admin:admin123


── Wrong Content-Type (not JSON) → 415 ──────────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: text/plain" ^
  -d "this is not json"


── Malformed JSON body → 400 ─────────────────────────────────

curl.exe -X POST http://localhost:8080/api/v1/records ^
  -u admin:admin123 ^
  -H "Content-Type: application/json" ^
  -d "NOT_JSON_AT_ALL"


── Wrong HTTP verb (DELETE /records — no ID) → 405 ──────────

curl.exe -X DELETE "http://localhost:8080/api/v1/records" ^
  -u admin:admin123
